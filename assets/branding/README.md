# Branding Assets

Folder ini disiapkan untuk aset resmi NER Text Assist.

Aset target:

- `ner-text-assist.ico` — Windows application/installer icon
- `ner-text-assist-256.png` — PNG 256x256
- `ner-text-assist-source.png` — sumber logo resolusi tinggi

## Aturan

Gunakan logo utama NER resmi sebagai base icon. Nama `NER Text Assist` dan gaya tipografinya boleh disesuaikan dengan fungsi aplikasi, tetapi bentuk utama logo NER tidak diganti.

Aset biner belum dimasukkan pada fondasi awal karena repository diinisialisasi melalui text-only GitHub actions. Tambahkan file logo resmi yang sudah disetujui sebelum build distribusi pertama.
